# 2048 (MSCS Department Edition)

Obsune Usso, Henry Pedersen

This version of 2048 follows the same logic as the original version, only this time, instead of numbers, we have MSCS faculty (specifically, their faces!). 

Players will be tasked with making bricks collide into larger and larger numbers with limited space, in order to make “2048”

To run code, run the Java program on the Game class, where the main method is. Use the arrow keys to move the blocks. You can exit the game by pressing the Esc key or instantly add a high-value block with the T key. The T functionality is for players to see what the game does after winning.

Technical requirements are Java 17/21 at a minimum for Kilt Graphics

No outside code was used, but much help was given by preceptors Lewis, Nurain, and especially by Professor Dan Drake. Thank you!

Known issues:

The main limitation is the lack of animation when moving/merging blocks, which was not very doable given the time constraint.

In order to trigger game loss, the user must try moving in all directions first, which may not be intuitive.

Societal impact:

The "rank" of each MSCS professor towards 2048 was done alphabeticaly, but the choice of which 11 to pick was biased. This game can not be played by someone who cannot input keyboard presses, nor someone who is blind. It is possible that the creator of the original 2048 game does not approve of recreations. It may be that people playing the game could view the professors on the "low" score end with lower value in reality as a result of the game.
